# 棋盤系統 (board_system)

> 棋盤渲染、格子類型、拖放部署、範圍預覽
> 最後更新：2026-06-28

---

## 一、概述

棋盤分上下兩半，各 8列×5行。玩家操作下半場，AI 控制上半場。

### 1.1 格子類型
| 類型 | CSS class | 說明 |
|------|-----------|------|
| 路徑格 | `cell-path` | 敵軍行進路線（U形），不可放置 |
| 解鎖格 | `cell-unlocked` | 可放置單位 |
| 鎖定格 | `cell-locked` | 需鏟子解鎖 |

### 1.2 路線定義
- **玩家**：左列↑ → 頂行→ → 右列↓（营=[4,0]，蔣=[4,7]）
- **AI**：右列↓ → 底行← → 左列↑（营=[0,7]，蔣=[0,0]）

---

## 二、拖放規格

### 2.1 手牌 → 棋盤
- 拖到空格：直接部署
- 拖到有單位（同兵種同等級）：合並升級
- 拖到有單位（不同）：替換，原單位退回手牌槽

### 2.2 棋盤 → 棋盤
- 拖到空格：移動
- 拖到有單位（同兵種同等級）：合並升級
- 拖到有單位（不同）：**交換位置**

### 2.3 棋盤 → 手牌槽
- 單位退回手牌，格子清空

---

## 三、視覺效果

### 3.1 拖動虛線
- 拖動時顯示從卡牌中心到當前位置的金色虛線
- SVG `<line>` 元素，stroke-dasharray="6,4"
- 顏色：rgba(255,215,0,0.75)

### 3.2 攻擊範圍圓圈
- 拖動懸停到某格時，顯示半透明白色圓圈
- 圓心：懸停格中心
- 半徑：range 個格子
